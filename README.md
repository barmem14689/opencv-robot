## Проект: робот‑машинка на OrangePi 3 LTS с компьютерным зрением

Этот проект реализует управление роботизированной машинкой на базе **OrangePi 3 LTS** и **Arduino Nano** с использованием **компьютерного зрения (OpenCV)**.  
OrangePi получает изображение с USB‑веб‑камеры, обрабатывает его в Python и передаёт управляющие команды на Arduino по **последовательному порту `/dev/ttyUSB0`**. Arduino уже управляет моторами (движение/поворот и т.д.).

Основное взаимодействие с OrangePi происходит по **SSH**: вы подключаетесь к плате по сети и запускаете нужные Python‑скрипты удалённо.

---

## 1. Аппаратные компоненты

- **OrangePi 3 LTS**
- **Arduino Nano** (часто на чипе **CH340** — важно для выбора правильного порта)
- **USB‑веб‑камера**
- **Моторы / драйвер моторов** (в зависимости от конструкции машинки)
- Питание для OrangePi, Arduino и моторов
- Соединительные провода для связи OrangePi ↔ Arduino (USB‑кабель)

---

## 2. Программные зависимости

На OrangePi должны быть установлены:

- **Python 3**
- Библиотеки Python:
  - `opencv-python` (или `opencv-python-headless`)
  - `numpy`
  - `pyserial`
  - `flask` (для варианта управления из браузера)

Пример установки (Debian/Ubuntu/Armbian-подобная система):

```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv

cd /path/to/project
python3 -m venv venv
source venv/bin/activate

pip install opencv-python numpy pyserial flask
```

## 3. Структура проекта

Ключевые файлы:

- `opencv-robot/examples/follow_red_color/red_detect.py`  
  Отслеживание **красного объекта** в кадре и отправка координаты в Arduino.

- `opencv-robot/examples/follow_face/face_detect.py`  
  Обнаружение **лица** при помощи каскадов Хаара и отправка его горизонтальной позиции в Arduino.

- `opencv-robot/examples/control_from_browser/app.py`  
  Веб‑приложение на **Flask**: поток с камеры + управление роботом из браузера через HTTP‑команды.

- `opencv-robot/examples/errors.py`  
  Текстовые сообщения об ошибках:
  - `Serial_Error` — проблемы с открытием порта `/dev/ttyUSB0`
  - `Camera_Error` — камера не найдена (нужно проверить индекс `cv2.VideoCapture`)
  - `Arrange_Error` — координаты вышли за допустимый диапазон (настроены под конкретную конструкцию робота)

## 4. Подключение к OrangePi по SSH

1. Определите IP‑адрес OrangePi (через роутер или `ip a` на самой плате).
2. Подключитесь по SSH с компьютера:

```bash
ssh orangepi@<IP-адрес-платы>
```

3. Перейдите в директорию проекта и активируйте виртуальное окружение (если используете его):

```bash
cd /path/to/opencv-robot-main
source venv/bin/activate
```

После этого можно запускать нужные скрипты.

---

## 5. Скрипт: отслеживание красного объекта (`red_detect.py`)

Файл: `opencv-robot/examples/follow_red_color/red_detect.py`

Функциональность:

- Открывает камеру: `cv2.VideoCapture(1)`  
  При необходимости можно сменить индекс на `0`, если камера одна.
- Находит красные области в HSV‑пространстве, выбирает самый крупный контур.
- Считает координату центра объекта по оси X.
- Преобразует координату в диапазон `0–255` функцией `zov(...)`.
- Отправляет одно байтовое значение в Arduino:
  ```python
  ser.write(bytes([FinalCoordinat]))
  ```
- В случае проблем с портом/камерой печатает сообщения из `errors.py`.

Настройки, которые можно менять под себя:

- `minimal_coordinate` и `maximal_coordinate` — ожидаемый диапазон X‑координат объекта в кадре.
- Порог площади объекта: `area > 500` — можно уменьшить/увеличить.
- Индекс камеры: `cv2.VideoCapture(1)` → `cv2.VideoCapture(0)` при необходимости.

Запуск по SSH:

```bash
cd /path/to/opencv-robot-main/opencv-robot/examples/follow_red_color
python3 red_detect.py
```

---

## 6. Скрипт: следование за лицом (`face_detect.py`)

Файл: `opencv-robot/examples/follow_face/face_detect.py`

Функциональность:

- Открывает камеру: `cv2.VideoCapture(1)`.
- Загружает каскад Хаара: `cascades/face.xml` (должен лежать рядом/в указанной папке).
- Находит лицо(а) на изображении, вычисляет центр по X.
- Преобразует координату в диапазон `0–255` с помощью `zov(...)`.
- Отправляет значение в Arduino:
  ```python
  ser.write(bytes([cx]))
  ```

Настраиваемые параметры:

- `minimal_coordinate` и `maximal_coordinate` — границы X‑координат лица в кадре.
- Путь к файлу каскада: `cascades/face.xml` (можно заменить на другой файл каскада).
- Индекс камеры.

Запуск по SSH:

```bash
cd /path/to/opencv-robot-main/opencv-robot/examples/follow_face
python3 face_detect.py
```

## 7. Управление из браузера (`app.py`)

Файл: `opencv-robot/examples/control_from_browser/app.py`

Функциональность:

- Поднимает веб‑сервер **Flask** на `0.0.0.0:8080`.
- Открывает последовательный порт `/dev/ttyUSB0` и камеру `cv2.VideoCapture(1)`.
- Генерирует MJPEG‑поток с камеры в обработчике `video_feed`.
- Отдаёт HTML‑страницу управления в обработчике `/`.
- При получении HTTP‑запросов вида `/cmd/<command>` отправляет `command` в Arduino:
  ```python
  ser.write(command.encode())
  ```

Пример сценария использования:

1. Запустить сервер по SSH:
   ```bash
   cd /path/to/opencv-robot-main/opencv-robot/examples/control_from_browser
   python3 app.py
   ```
2. На основном компьютере открыть браузер и перейти по адресу:
   - `http://<IP-адрес-OrangePi>:8080/` — страница управления.
   - `http://<IP-адрес-OrangePi>:8080/video_feed` — поток с камеры.
3. Кнопки/элементы управления на странице отправляют команды на `/cmd/...`, которые приходят на Arduino.

## 8. Обработка ошибок (`errors.py`)

Файл: `opencv-robot/examples/errors.py`

Содержит текстовые сообщения:

- **`Serial_Error`** — проблемы с открытием порта `/dev/ttyUSB0`.  
  Проверьте:
  - Подключение Arduino (особенно если используется CH340).
  - Какой порт выбран в Arduino IDE.
  - Права на доступ к последовательному порту.

- **`Camera_Error`** — камера не найдена.  
  Возможные причины:
  - Неправильный индекс камеры (`cv2.VideoCapture(1)` → `cv2.VideoCapture(0)`).
  - Камера не подключена или занята другим процессом.

- **`Arrange_Error`** — координаты вне ожидаемого диапазона.  
  Нужно перенастроить `minimal_coordinate` и `maximal_coordinate` под вашу геометрию/угол установки камеры.

## 9. Типичный рабочий процесс (через SSH)

1. Включить OrangePi и дождаться загрузки ОС.
2. Подключиться по SSH с основного компьютера:
   ```bash
   ssh orangepi@<IP-адрес-платы>
   ```
3. Перейти в папку проекта и (опционально) активировать виртуальное окружение.
4. Запустить нужный скрипт:
   - Отслеживание красного объекта: `python3 red_detect.py`
   - Следование за лицом: `python3 face_detect.py`
   - Управление из браузера: `python3 app.py`
5. Наблюдать поведение робота и при необходимости корректировать:
   - Индекс камеры.
   - Диапазоны координат.
   - Параметры распознавания.

---

## 10. Дополнительные замечания

- Код использует простую передачу **одного байта (0–255)** в Arduino. Логику интерпретации этого байта (управление сервоприводом/моторами) нужно реализовать в прошивке Arduino.
- В проекте есть «жёстко зашитые» значения диапазонов координат, подобранные под конкретного робота. При переносе на другую машинку эти значения почти наверняка нужно перенастраивать.
- Для стабильной работы видео и управления по сети рекомендуется проводное подключение OrangePi к роутеру.
